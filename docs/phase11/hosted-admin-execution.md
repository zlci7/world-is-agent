# 托管管理后台执行边界

日期：2026-10-19

## 交付范围

- `/admin/login` 为管理员账号密码登录，`/admin` 为独立管理站点。管理会话与玩家会话隔离，复用账号库、密码校验和角色机制。
- 管理员使用简洁中文布局、纯色背景和固定侧栏，包含总览、用户、邀请码、用量审计、操作日志。玩家端保留现有视觉与功能。
- 用户可以按邮箱或 ID 查询，展示验证、启停、来源邀请、有效日额度和用量。日额度支持继承默认值或个人覆盖；调整记录前后值和原因。
- 邀请码一次注册一人，创建支持有效期和备注，列表展示兑换账号与时间。撤销仅影响未兑换邀请。
- 每日额度使用 UTC。账号与全站准入在同一 SQLite 事务中检查；已结算与未结算占用分别展示。限额调整从后续请求生效，原账本保留。
- 用量按日期和账号汇总并支持请求明细、状态筛选及有界 CSV 导出。历史缺失的请求时间、模型和输入输出量明确表示未知。
- 初始管理员由私有命令初始化；管理页面仅提供登录。权限变化与会话过期清除管理视图。

## 架构与限制

账号及额度继续使用单控制进程 SQLite。迁移保留账号 ID、凭据、邀请关联和历史消耗，迁移前备份现有数据库。Runtime Core、Protocol、Adapter、游戏存档和现有记忆机制不进入改动范围。

全站日额度来自托管配置；个人覆盖属于账号数据。邀请码不承担后续授权或额度配置。首版不包含人民币计费、充值、通用角色系统、批量数据删除、容器操作、任意查询及手工清空预留。

## 验收条件

- 普通玩家会话不能访问管理 API，管理员登录不建立玩家会话；管理页访问不会分配或启动 Runtime。
- 并发账号请求同时遵守个人及全站限额，未知调用保留预留；降低限额不改写历史。
- 邀请、额度和启停写操作有权限及 CSRF 校验，额度调整有原因、前后值和事务审计。
- 注册来源、请求汇总与明细对应，CSV 与筛选一致，导出受行数和日期范围限制。
- 桌面与窄屏真实浏览器检查覆盖登录、五个栏目、写入失败、读取失败、无结果和权限失效。
- 相关 Go 测试、race、完整回归、前端类型/顺序/构建、架构检查、内部 CR 和文档链接检查通过后本地提交；不 push。
