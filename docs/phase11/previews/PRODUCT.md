# 产品与样稿范围

## 平台

Windows 游戏玩家使用的本地 Web 控制台。正式前端为 Vue 3；本目录为 HTML、CSS 和 JavaScript 静态样稿。

## 用户与目标

玩家在游戏中建立 NPC 预约，在浏览器中查看任务是否登记、当前状态、暂停原因与真实结果，并配置游戏和模型。

## 已确认约束

- 产品名为 World Is Agent。界面采用中文，游戏风格，保持清晰对齐和良好阅读性。
- 样稿包含预约任务、运行概览、游戏与模型和运行记录，保留当前产品功能及配置语义。
- 任务首版只读，权威数据来自 Runtime Task SQLite；浏览器不成为第二份任务存储。
- 任务状态与世界可用性分别表达，不把游戏离线记为任务失败。
- 样稿使用示例数据，不连接 Runtime，不提交真实配置。
- 正式前端采用已确认的像素风、分层透明窗口和按游戏区分的背景；静态样稿保留其它视觉参考。
- 允许重新设计现有布局，保留现有功能和操作语义。
- 视觉候选包含像素风与按游戏切换背景：星露谷田园场景、环世界殖民地场景，共用任务与配置布局。
- 像素窗口采用分层透明背景，正文与控件保持完全不透明；游戏配置生效后直接更新主题，提交忙碌态和失败原因就近展示。
