## 真实模型与体验

模型为当前本地配置的 DeepSeek `deepseek-v4-flash`，使用默认接口。凭据更新后的两条鉴权场景成功，401 阻断已解除。测试通过 Runtime 的配置与凭据解析、真实 Loop、源码 definition、能力目录和独立 SQLite 历史执行；模型输出预算为 2048 tokens。凭据未写入场景、日志或文档。

Environment 提供合成 Observation 与动作结果，不连接或操作游戏。能力目录取自 Adapter 的普通对话与移动能力；本轮不覆盖完整预约、邮件或真实动作执行。单轮矩阵使用每场景独立的世界与历史，连续场景使用每 NPC 独立的世界和历史。

| 真实模型检查 | 结果与证明范围 |
| --- | --- |
| 34 人各八条基础场景 + 24 条目标场景 | 296 条均完成且各有一个可见对话；长度、选项数量、去重与自由输入形态通过。基础场景包含初识、熟悉、人物关系、设施前后、未见事件、错误暗示与未知；不构成完整剧情覆盖 |
| 五类目标边界各五次 | 共 25 条完成且有可见对话；检查未通公交、已通公交、停止钓鱼、零计数自报完成、已达数量待报告。本批没有将达标说成已交付、要求携鱼提交或保证次日仍有效 |
| Abigail、Robin、Linus 各 20 轮 | 首批 60 轮中 51 轮完成，Linus 的九轮出现 JSON 解析失败；单独 Linus 20 轮与带诊断的完整 60 轮复跑均完成。间歇异常尚未定位，复跑成功不等于稳定性问题已解决 |
| 连续历史与当前事实 | 成功样本能承接放慢节奏、不接收集任务的偏好，且不反复自我介绍；模拟换日与第 11 轮重建 Loop 后仍可读取历史。设施状态变化与未知场景能响应，但具体叙述仍有失真 |

连续测试中的换日和 Loop 重建均为合成条件，不代表真实 Runtime 进程重启、游戏保存加载或回档已通过。

以下事项保留为未通过项：

- JSON 解析失败的来源尚不能定位到 HTTP 响应体或工具参数；首次失败缺少原始响应，带诊断的复跑未复现。需要取得可复现证据后才能确认根因与修复。
- 个别回答仍有时段口误、以“游戏里”等词解释提交的出戏表达，以及没有事实支持的行动归因，例如 Robin 将可用温室说成自己修复。角色差异与偏好承接已有样本，世界知识和执行结果叙述尚不足以整体放行。
- 玩家是否采用建议、是否因此更愿意继续游玩，尚无真实游戏体验证据。

本地模型证据位于 `runtime/.local/phase11.15/llm/`：`auth-after-key-update.jsonl`、`matrix-current-definitions.jsonl`、`boundary-current-definitions.jsonl`、`continuity-current-definitions.jsonl`、`linus-diagnostic-results.jsonl` 和 `continuity-diagnostic-results.jsonl`。诊断目录保留合成场景关联、响应格式与回答内容，不记录请求头或凭据。场景完成数量表示调用与对话形态结果，不是语义正确率。

真实模型对合成观察的回答与真实游戏交互分别记录，前者通过不能代替后者。

## 实机验收步骤

使用测试存档副本，安装当前源码构建的 Adapter，并让 Runtime 使用本轮 definition。已有数据根保留现有文件，需先备份再按官方文件清单更新；保持模型配置、自定义文件、Memory 和 Task。

| 场景 | 操作 | 预期与失败时行为 |
| --- | --- | --- |
| 普通聊天 | 空手点击无原生提交的 NPC | 进入中文 AI 对话；Runtime 不可用时保留原生交互 |
| 送礼 | 手持无匹配交付任务的礼物互动 | 按原版处理接受或拒收，不进入 AI 等待，也不多扣物品 |
| 原生交付 | 接任务后手持正确、错误和数量不足的物品分别互动 | 原版校验与处理；只有真实完成才能承接成功 |
| 钓鱼计数 | 接取 Willy 原生钓鱼任务，钓前、未够、够数分别询问 | 读取当前任务与真实计数，不以口头自报替代 |
| 钓鱼提交 | 达到数量后空手与 Willy 互动 | 放行原版报告；计数达标不提前当作任务完成或领奖 |
| 后续承接 | 完成后再次聊天，再重启 Runtime | 当前游戏结果可以供 Willy 承接，无重复交付或发奖 |
| 原生状态移除 | 分别取消、过期、领奖移除 | 未观察到完成时为 unavailable；不从消失推断原因 |
| 保存加载 | 未完成和完成状态分别保存、退出、重新加载 | 关联跟随当前游戏存档，重新读取事实 |
| 回档 | 完成后回到任务仍未完成的存档 | 当前原生状态优先，不沿用未来的完成结论 |
| 关系与设施 | 恋爱／室友变化、修复安排当日与生效次日分别询问 | 读取真实身份和设施状态；未知时不猜测 |
| Dwarf | 未学会与已学会语言分别互动 | 未学会时沿用原生交互；已学会后才进入可用 AI 入口 |

预约另按 [11.1 恢复矩阵](phase11.1-acceptance.md) 验收。普通聊天 Memory 的废弃分支隔离限制仍存在；原生任务 metadata 不构成对通用 Memory 回档问题的修复。

## 玩家价值门槛

至少五次真实目标协作，记录目标、当前进度、建议、是否采用、实际行动和反馈。至少三次采用且至少三次能说明具体帮助，同时没有已知进度错误、虚构修改规则或假完成，才评估新增一种受限委托。当前没有这组试玩证据。
